# Coffer 项目未完成事项排查

检查日期：2026-10-26（Asia/Hong_Kong）。检查基线：Git `9784e06` 加检查开始时已有的工作区改动；并非已发布安装包。

## 1. 先看结论

项目已经具备较完整的核心实现：文件保存、解析与模型建议、确认归档、搜索与引用、撤销与持久恢复、Web 账号隔离、桌面个人文件库、备份及部署工具。接下来不宜继续按早期计划“从头补功能”，应优先处理**当前功能衔接缺口、测试与文档同步，以及当前版本的真实环境验收**。

本次发现两处直接影响使用的衔接问题：本地模型模式下的重新分析请求仍固定指定 API 模式；Web 上传进度仍主要按分析/标签状态显示“已完成”，未统一到归档状态。另有一份账号隔离浏览器测试的夹具已过时。具体代码、影响和修正建议见[项目优化检查报告](项目优化检查报告.md)。

以下状态严格区分：

- **代码缺口**：根据当前代码调用链确认需要修正。
- **已实现、待验收**：已有代码或历史结果，但缺当前版本、指定环境的完成证据。
- **待核实/条件项**：涉及实际设备、在用版本、历史数据或学校要求，本次不能代替现场确认。
- **范围外**：不算遗漏，不自动加入待办。

优先级：P0 为相应正式发布前必须关闭的事项；P1 为近期功能及质量收尾；P2 为持续改进或按实际需要推进。P0 并不表示已经发现数据丢失或严重漏洞。

本报告是本次排查快照；后续完成状态仍建议回填[进度与问题](进度与问题.md)，避免再形成互相矛盾的长期清单。
