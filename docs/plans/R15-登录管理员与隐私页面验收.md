# R15 登录、管理员和隐私页面验收

## 页面与服务端边界

- 首次部署通过一次性部署令牌创建管理员。登录使用服务端 JDBC 会话和 CSRF Cookie；普通账号由管理员创建、停用、启用或重置密码。普通用户只能进入自己的工作区。
- 管理员进入独立控制台，只能读取账号操作和固定维度的运行数量。导航不渲染文件、搜索、对话、模型设置；直接输入私有页面地址进入无权访问页。后端 `/api/admin/**` 和普通 `/api/**` 分别校验角色，管理员不能通过私有 API 取得用户内容。
- 同一浏览器内账号变化时，前端立即取消进行中的请求，用身份代次拒绝迟到响应，卸载旧页面，清理标签选择、文件抽屉、对话引用与弹窗。其他标签页检测到登录身份变化后清空本地页面状态。会话失效回登录页并显示原因。
- 设置页展示用户模型目标、自动导入授权、仅用量诊断、个人数据导出与删除。导出 ZIP 在响应开始前生成完整文件，包含有 owner 约束的元数据清单与文件原件，不包含登录密码、模型 API 密钥或加密任务快照。用户在文件页选择文件删除，对象与向量清理进度在设置页明确显示。
- “删除全部对话与记忆”要求明确确认；服务端在同账号存在进行中操作时返回 409，避免删除后被运行中的对话重新写入。会话与消息在数据库提交后立即失效。Redis 暂时不可用时，按精确 owner+会话键持久化重试；设置页可查看待清理数量。

## 已执行验证

`PrivacyIntegrationTest` 以真实 H2/Flyway V21、Spring 安全过滤器和 JDBC 会话验证：双用户导出内容严格隔离，管理员与匿名请求拒绝；删除 A 的对话后 B 的会话仍可用；Redis 失败留队并重试；删除与活动请求冲突时不执行。

`frontend/tests/identity-isolation.mjs` 使用独立无头 Edge，在**同一个浏览器窗口**按 Alice → Bob → Alice → 管理员 → Bob 顺序登录。断言文件详情抽屉、列表、延迟响应、管理员页面/API、直接访问禁区和过期会话没有跨身份内容。该浏览器测试使用受控 API 响应；后端角色和数据授权由上面的集成测试及 R12/R13/R14 验证。

未把浏览器模拟结果冒充桌面外壳、真实 Redis/MinIO 或多应用实例验收。浏览器测试使用受控 API 响应；真实后端与 Vue 前端已通过一键启动健康检查，本机 MySQL 执行 Flyway V16–V21。删除活动门闩在单个后端进程内有效；未来多实例部署需改为数据库或分布式门闩。旧版遗留匿名单用户 fixture 已按账号契约更新；后端全量回归 275 项通过（0 失败、0 错误）。
