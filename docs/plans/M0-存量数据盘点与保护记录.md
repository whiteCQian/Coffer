## 用户决策与切换规则

1. 用户确认旧单用户业务数据可直接删除，不需要将其 owner 回填到新用户。
2. 执行清理前再次确认清理目标环境、维护窗口和恢复点；停用旧应用写入；对 MySQL、MinIO、H2 和密钥材料生成并校验切换快照。
3. 清理清单限定为旧 agentfs schema 中 Flyway 以外的业务行和 MinIO 的完整 agentfs-bucket；不删除 Flyway schema/迁移历史，不删除 MinIO 的其他 bucket 或内部数据目录，不触碰工作区 H2/Redis 文件。先导出表行数、bucket 对象数、SHA-256 清单与命令日志，再在旧应用停写维护模式下执行可重复的清理步骤。
4. 旧数据清理后从空库初始化新实例和首次管理员；不得把备份自动导入管理员账号。
5. 备份在新系统验收通过及约定保留期结束前保留。其后由用户依据数据保留要求明确清除；该动作不自动执行。
