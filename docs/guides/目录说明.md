# 项目目录说明

## 日常入口

- 根目录：`README.md`、`start-all.bat`、`stop-all.bat`；本机配置 `coffer-local.cmd` 保留原位。
- `backend/`：Java 后端代码、测试及 Maven 配置。
- `frontend/`：Vue 前端代码、测试及 npm 配置。
- `desktop/`：Electron 桌面应用、安装资源、打包配置及测试；`build/` 是打包资源，`.build/` 和 `dist/` 是本地产物。
- `scripts/`：启动、停止、构建、备份和验收脚本。
- `.github/`：持续集成配置。

## 文档分类

- `docs/` 根目录：项目总览、需求范围、架构图、已知问题。
- `docs/api/`：API 契约。
- `docs/architecture/`：代码与实现说明。
- `docs/decisions/`：架构决策。
- `docs/plans/`：执行计划、需求追踪及各阶段验收记录。
- `docs/product/`：选题与产品范围资料。
- `docs/guides/`：使用和维护说明。
- `docs/archive/`：历史方案、交接材料及旧 SQL。

## 日志与运行数据

- `logs/`：启动脚本及从根目录运行时生成的日志。
- `backend/logs/`：从后端工作目录运行时生成的日志；保留该位置以兼容当前配置。
- `logs/archive/2026-10-09/backend/`：原散落在 `backend/` 下的 R12–R23 测试与回归日志。
- `logs/archive/2026-10-09/root/`：原根目录中的历史回归日志。
- `logs/archive/2026-10-09/diagnostics/`：原 `logs/` 和 `.coffer-runtime/` 中的探测、Redis/MinIO 测试日志。
- `.coffer-runtime/`：受管进程状态及运行辅助文件；`redis-data/` 是当前启动脚本使用的 Redis 数据目录。
- `.coffer-runtime/archive/redis/root-dump.rdb`：原根目录 `dump.rdb` 的归档副本位置，保留原始内容，与当前 Redis 数据分开保存。
- `.coffer-runtime/archive/external/NVIDIA Corporation/`：整理时为空的显卡诊断目录。
- `data/`、`backend/data/`：已有本地数据库，保持原位。

历史文件仅移动，没有删除。此次移动清单保存在本机 `logs/archive/2026-10-09/moves.json`，记录原路径、新路径和文件 SHA-256，可据此逐项还原；该清单及归档日志不纳入 Git。

## 本地生成目录

`node_modules/`、`target/`、`dist/`、`.build/`、`.vite/`、各模块的 `.test-tmp/` 和 TypeScript 的 `*.tsbuildinfo` 由依赖安装、构建或测试生成，按现有工具要求保留原位。`.idea/` 保存本机 IDE 配置，`.git/` 保存版本历史。

后续测试输出建议直接写入 `logs/` 或指定测试目录，历史日志按日期放入 `logs/archive/`，避免再次散落到根目录和模块根目录。运行数据、密钥及验收样本应保留各自的数据位置。
